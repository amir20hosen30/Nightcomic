# MangaNova — NightComic UI

نسخه‌ی React/Vite از رابط NightComic با برند و استایل MangaNova.

## اجرای محلی
```bash
npm install
npm run dev
```

## ساخت برای GitHub / هاست
```bash
npm run build
```

خروجی نهایی داخل `dist` ساخته می‌شود.

> این نسخه مستقل است و کاتالوگ نمونه‌ی داخل NightComic را نگه می‌دارد. برای اتصال به بک‌اند کامل MangaNova باید APIهای پروژه اصلی به این UI متصل شوند.
